4 — Guide complet Windows (A à Z)

① Installer FFmpeg — une seule fois

⚠️
Si ffmpeg -version fonctionne déjà dans votre CMD, passez directement à la phase ②.
1

Télécharger FFmpeg

Allez sur https://www.gyan.dev/ffmpeg/builds/ et téléchargez le fichier ffmpeg-release-essentials.zip (environ 103 Mo).

2

Installer dans C:\ffmpeg

Décompressez l’archive. Renommez le dossier en ffmpeg et déplacez-le à la racine de C.

Le chemin final doit être : C:\ffmpeg\bin\ffmpeg.exe

3

Ajouter C:\ffmpeg\bin au PATH Windows

Appuyez sur Win + R, tapez SystemPropertiesAdvanced et appuyez sur Entrée.

Cliquez sur « Variables d’environnement… » → dans la section Variables système, double-cliquez sur Path → Nouveau → collez C:\ffmpeg\bin → OK (3 fois).

4

Vérifier l’installation

Ouvrez un nouveau CMD : Win + R → cmd → tapez ffmpeg -version. Vous devez voir le numéro de version.

② Fusionner les vidéos — à chaque utilisation

1

Préparer les fichiers

Placez vos séquences dans un même dossier. Ne mélangez pas AVI et MP4 si vous souhaitez utiliser le mode «copy» (sans réencodage). Si mélange inévitable, utilisez le mode réencodage MP4 (H.264).

2

Générer les commandes dans cet outil

Glissez-déposez vos fichiers. Le format est détecté automatiquement. Cliquez sur « Générer les commandes FFmpeg ».

3

Naviguer vers le dossier vidéos dans CMD

Dans l’Explorateur Windows, ouvrez votre dossier vidéos, cliquez dans la barre d’adresse, tapez cmd et appuyez sur Entrée.

4

Créer le concat.txt (commande ①)

⚠ Commande générée automatiquement avec vos vrais noms de fichiers.

Copiez et collez dans le CMD. Vérifiez avec type concat.txt.

5

Lancer la fusion (commande ②)

Copiez la commande FFmpeg et collez-la dans le CMD. La fusion sans réencodage est quasi-instantanée.

6

Vérifier le résultat

Le fichier fusionné apparaît dans votre dossier. Ouvrez-le avec VLC pour vérifier.

Note technique

ℹ️

Sans réencodage (copy) : quasi-instantané, zéro perte de qualité. Nécessite des séquences du même format, même codec, même résolution et même fréquence d’images.

Réencodage MP4 (H.264 + AAC) : format universel, compatible tous lecteurs. Recommandé pour les mélanges ou si le «copy» génère des artefacts.

Réencodage AVI (MPEG-4 + MP3) : préserver le conteneur AVI en cas de contrainte spécifique (logiciel legacy, exportation particulière).

Mélange AVI + MP4 : FFmpeg ne peut pas concaténer des conteneurs différents en mode copy. Le réencodage MP4 est la solution universelle.

Erreur « unknown keyword file » : le concat.txt a été créé avec Notepad (BOM). Toujours utiliser la méthode CMD avec echo générée par cet outil.
