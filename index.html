📖 Mode d'emploi - Recherche Copernic

Cet outil indexe le contenu de vos documents (PDF, DOCX, TXT) pour une recherche plein texte locale.

🚀 Utilisation immédiate (Recommandé)

  • 1. Cliquez sur ➕ Ajouter un dossier et sélectionnez un dossier de votre PC
  • 2. L'indexation extrait le texte des fichiers automatiquement
  • 3. Tapez votre recherche : les résultats s'affichent en temps réel avec surlignage
  • 4. Cliquez sur 📋 Copier le chemin pour ouvrir manuellement le fichier

⚙️ Configuration

  • Racine du dossier : Définissez le chemin de base (ex: C:\Users\Nom\Documents) pour que les chemins affichés soient corrects
  • Persistance : L'index est sauvegardé dans votre navigateur (localStorage)

💡 Mode Expert (Optionnel)

Pour activer l'ouverture directe des fichiers (boutons Ouvrir/Localiser), vous devez héberger cet outil localement avec Node.js. Voir le fichier server.js inclus.
  • Installez Node.js depuis https://nodejs.org
  • Dans le dossier, lancez : node server.js
  • Accédez à http://localhost:3456

🔒 Confidentialité

  • Tout le traitement se fait localement dans votre navigateur
  • Aucun contenu de fichier n'est envoyé vers un serveur externe
  • L'index reste stocké sur votre appareil
