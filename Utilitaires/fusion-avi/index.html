4 — Guide complet Windows (A à Z)

① Installer FFmpeg — une seule fois

⚠️
Si ffmpeg -version fonctionne déjà dans votre CMD, passez directement à la phase ②.
1

Télécharger FFmpeg

Allez sur https://www.gyan.dev/ffmpeg/builds/ et téléchargez le fichier ffmpeg-release-essentials.zip (environ 103 Mo).

2

Installer dans C:\ffmpeg

Décompressez l'archive. Vous obtenez un dossier nommé ffmpeg-8.x.x-essentials_build.

Renommez-le en ffmpeg et déplacez-le à la racine du disque C.

Le chemin final doit être : C:\ffmpeg\bin\ffmpeg.exe

3

Ajouter C:\ffmpeg\bin au PATH Windows

Appuyez sur Win + R, tapez SystemPropertiesAdvanced et appuyez sur Entrée.

Cliquez sur le bouton « Variables d'environnement… » en bas de la fenêtre.

Dans la section « Variables système » (partie basse), double-cliquez sur Path.

Cliquez sur « Nouveau » et collez exactement : C:\ffmpeg\bin

Cliquez OK sur toutes les fenêtres (3 fois de suite).

4

Vérifier l'installation

Ouvrez un nouveau CMD : Win + R → tapez cmd → Entrée.

Tapez : ffmpeg -version

Si vous voyez ffmpeg version 8.x.x, FFmpeg est prêt.

② Fusionner les vidéos — à chaque utilisation

1

Préparer les fichiers

Placez toutes vos séquences AVI dans un même dossier. Renommez-les simplement : video1.avi, video2.avi, video3.avi, etc.

2

Générer la commande dans cet outil

Glissez-déposez vos fichiers AVI dans la zone ci-dessus. Vérifiez l'ordre. Choisissez le nom du fichier de sortie. Cliquez sur « Générer la commande FFmpeg ».

3

Créer le fichier concat.txt via CMD

⚠️ Ne pas utiliser le Bloc-notes (Notepad) — il ajoute un marqueur invisible (BOM) qui casse FFmpeg.

Ouvrez le CMD (Win + R → cmd). Naviguez vers votre dossier vidéos :

cd C:\Users\VotreNom\Videos

Créez le concat.txt avec la commande suivante (adaptez les noms de fichiers) :

(echo file 'video1.avi' & echo file 'video2.avi' & echo file 'video3.avi') > concat.txt

Vérifiez avec type concat.txt — chaque ligne doit afficher file 'nom.avi'.

4

Lancer la fusion

Copiez la commande générée (bouton « Copier la commande »), collez-la dans le CMD et appuyez sur Entrée.

FFmpeg affiche la progression. La fusion sans réencodage est quasi-instantanée.

5

Vérifier le résultat

Le fichier fusionné (fusion_finale.avi ou le nom choisi) apparaît dans votre dossier. Ouvrez-le avec VLC ou Windows Media Player.

Note technique

ℹ️

Sans réencodage (copy) : fusion quasi-instantanée, zéro perte de qualité. Fonctionne si toutes les séquences ont le même codec, la même résolution et la même fréquence d'images — cas typique des séquences issues du même appareil.

Avec réencodage (MPEG-4) : plus lent, mais fusionne des séquences hétérogènes. Légère perte de qualité due à la recompression.

Erreur « unknown keyword file » : le concat.txt a été créé avec Notepad (BOM invisible). Toujours utiliser la méthode CMD avec echo.
