Recherche locale de fichiers

Ajoutez un dossier pour indexer son contenu, puis recherchez instantanément.

📖 Mode d'emploi - FileSearch

Ce logiciel vous permet de chercher des mots précis à l'intérieur de vos documents (Word, PDF, txt...) stockés sur votre PC, sans utiliser internet.

⚠️ Prérequis Indispensable : Installer Node.js

IMPORTANT : Pour que ce logiciel fonctionne (surtout si vous changez d'ordinateur), le moteur "Node.js" doit être installé sur Windows.
  • Allez sur le site officiel : https://nodejs.org
  • Téléchargez et installez la version recommandée (LTS).
  • Sans ça, la commande node ne fonctionnera pas !

🚀 1. Démarrer le Serveur

  • Ouvrez une invite de commandes (CMD) dans le dossier de FileSearch.
  • Tapez : node server.js et appuyez sur Entrée.
  • Laissez la fenêtre noire ouverte en arrière-plan.

⚙️ 2. Configuration : La "Racine" (À faire une fois)

  • Dans la barre jaune "Racine du dossier", tapez le chemin général où se trouvent vos fichiers (ex: C:\Users\nom\Documents).
  • Cliquez sur Enregistrer.

🌐 3. Ouvrir la bonne adresse Web

  • Ne faites pas un simple double-clic sur le fichier !
  • Ouvrez votre navigateur internet et tapez exactement cette adresse :
    http://localhost:3456/copernic-local.html

📁 4. Mémoriser vos dossiers (Indexation)

  • Cliquez sur + Ajouter un dossier et sélectionnez un dossier sur votre PC.
